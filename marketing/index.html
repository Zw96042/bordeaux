Bordeaux installs managed support only after a preview, discovers team-owned annotated factories through a deterministic catalog, and validates arguments before export.

It never edits RobotContainer and never deploys robot code.

ExampleCommands.java
public final class ExampleCommands {
  @BordeauxCommand(
      id = "intake.hold",
      label = "Hold intake")
  public Command hold(
      @BordeauxParam(
          label = "Output",
          min = "-1",
          max = "1")
      double output) {
    return Commands.startEnd(
        () -> intake.set(output),
        intake::stop,
        intake);
  }
}

Questions, answered plainly.

Is Bordeaux ready for competition use?

Bordeaux is beta software. Validate exported trajectories in simulation and on a safely controlled robot, and keep a known-good autonomous fallback.

Which robots and languages does it support?

The maintained application is focused on FRC and Java 17, with swerve and tank robot models.

Does Bordeaux change or deploy robot code?

No. It previews managed support changes, does not edit RobotContainer, and never performs robot deployment.

Which platforms are packaged?

The repository includes packaging targets for macOS, Windows, and Linux. Check each beta release for the exact available artifacts.

Is Bordeaux open source?

Yes. The source, releases, issue tracker, and current license are available in the public GitHub repository.
