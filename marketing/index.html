Bordeaux is beta software. Validate exported trajectories in simulation and on a safely controlled robot, and keep a known-good autonomous fallback.

Which robots and languages does it support?

The maintained application is focused on FRC and Java 17, with swerve and tank robot models.

Does Bordeaux change or deploy robot code?

No. It previews managed support changes, does not edit RobotContainer, and never performs robot deployment.

Which platforms are packaged?

The repository includes packaging targets for macOS, Windows, and Linux. Check each beta release for the exact available artifacts.
