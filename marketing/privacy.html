Privacy · Updated August 19, 2026

Local by design.

This page describes the current public website source and the Bordeaux beta desktop application. If hosted behavior changes, this notice should be reviewed before launch.

Marketing website

The website included in this repository does not load analytics, advertising pixels, third-party embeds, marketing cookies, or browser storage. Download, source, release, and issue links lead to GitHub, where GitHub’s own privacy terms apply.

Desktop application

Bordeaux project files are opened and saved on the operator’s computer. The application does not include a telemetry or advertising client in the current source. Supported packaged builds contact GitHub Releases shortly after startup to check version metadata and automatically download an available update; GitHub receives the ordinary network request data covered by its privacy terms, but not the contents of Bordeaux project files. Teams remain responsible for reviewing project contents before sharing them.

Java projects and builds

When asked, Bordeaux can preview and install managed Java support files, then run a fixed Gradle catalog task inside a team-selected robot project. Gradle build scripts are code and may use the computer or network according to that project’s configuration. Bordeaux does not edit RobotContainer and does not deploy robot code.

Optional agent access

Local MCP access is off by default. When an operator enables it, Bordeaux exposes a private local session so a configured client can inspect the open project and propose changes. Proposals still require an explicit Apply action in the editor.

Questions

For questions or corrections, open an issue in the Bordeaux repository.
