Executive assessment

The original code was not broadly careless; its failures were cross-boundary contract gaps. The repair program now makes the selected planner authoritative in previews and export, preserves waypoint/action provenance, bounds valid maximum documents before expensive allocation or transfer, preflights Java autonomous work before motion, and makes Electron/MCP ownership explicit.

Verdict: no reproduced release blocker remains in merged commit afdd9728. The tree passes the complete release suite, signed package verification, browser correctness/performance checks, and three independent final reviews. PRs #48–#75 and harness follow-up #82 are merged.

Remediation and PR topology

  1. Planner stack: angular safety and wait validation first, then authoritative previews, waypoint indexing/provenance, and finally the single-pass stationary-action optimization. Each behavior change has its own commit boundary.
  2. Renderer siblings: Reverse anchors, brush correctness/frame work, routine caching/workers, exact async path previews, aggregate admission, and Reverse gating remain distinct merge units.
  3. Java stack: follower overflow is independent; autonomous preflight is the foundation for bounded event catch-up and later-path preflight; between-path command waiting has an explicit transition API and legacy migration guard.
  4. Electron/MCP siblings: focused-draft persistence, desktop ownership, stdio EOF, streamed bridge resources, bounded Java reads/build admission, and canceled-quit lifecycle are separate branches with only their real file-level dependencies stacked.
  5. The integrated branch exists only as a release oracle. Maintainers can merge or decline the smaller branches and restack descendants without accepting an all-or-nothing mega-PR.
