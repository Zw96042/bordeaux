Context

Recommendation

Use one branch per independent behavioral contract and short stacks only where one change genuinely depends on another. Every performance pull request carries a reproducible benchmark fixture with baseline, fixed result, hardware/runtime context, and percentage improvement. Every correctness pull request adds a failing regression before changing production code.

Implementation steps

  1. Capture each deterministic reproducer as a regression test or benchmark before modifying its implementation.
  2. Implement the smallest contract-preserving fix on a descriptive fix/… or perf/… branch based on current Bordeaux main.
  3. Keep commits cohesive and normally near 100 changed lines; use lowercase Conventional Commit descriptions such as fix(planner): enforce signed angular acceleration.
  4. Run focused tests and before/after measurements on each branch, then run the complete release matrix on a temporary integration branch containing every fix.
  5. Perform an independent read-only review of the integrated diff, repair blocking findings on the owning branch, and re-run affected checks.
  6. Push only to a confirmed Bordeaux-compatible repository, create independently mergeable PRs/stacks, link every Lab card to its exact PR, and close cards only after merge.
