Resulting behavior

  • Paths and Routines share a persistent library beside the field. Search, folders, inline naming, duplication, reference-aware deletion, endpoint linking, batch selection, and remembered per-tab layout stay in the editor.
  • A compact push review names the selected paths or routine, dependencies, and preserved robot content. Selection changes and later edits cannot mutate confirmed bytes.
  • Complete snapshots are composed from a validated active revision. A path push preserves unselected deployed paths and the deployed routine; an explicit routine push replaces that routine and includes its complete linked dependency closure.
  • Connection, history, pin, rollback, full-project recovery, and diagnostics share the application-owned controller. Receipt and content comparison checks keep stale, foreign-project, or unconfirmed content from appearing synchronized.

Structural redesign after owner rejection

The earlier feedback pass passed functional checks but failed the owner's product expectations. The next pass replaces its cards, explicit Select mode and expanding action blocks, and implements the flow-first Aquitaine workspace instead of leaving the central-layout change as a proposal.

  • Compact flat rows with direct click, modifier toggle, range and keyboard selection. Selection is tied to the active editing context, so opening a path from a routine or creating a path cannot restore an unrelated batch or range anchor.
  • Direct New folder action and a native top-layer popup for each named path's actions. Append accepts the explicit source path ID. Folder/link properties live in a focused dialog. Menus dismiss with Escape or outside clicks and reopen reliably under React 18 using a native toggle listener.
  • Full-height central routine flow with responsive branch lanes, a Flow/Field preview switch, existing playback, preserved node editing, and a dismissible inspector. The left library retains its width and the shared toolbar controls retain their positions across modes.

Independent review identified popup dismissal state, a mismatch between the sole selected push target and its label, stale selection across routine-to-path navigation, and a stale range anchor after path creation. All were corrected and exercised in actual Electron interaction tests.
