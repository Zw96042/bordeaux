Delivered a complete, copyable GradleRIO robot project that demonstrates the Bordeaux annotation, catalog, export, and WPILib event-runtime lifecycle end to end.

Context

The repository currently has correct integration snippets but no project that can be selected directly through Java → Link Robot Project. The template must remain a normal team-owned GradleRIO project: Bordeaux installs its local support through the existing reviewed workflow and must not ship duplicate support binaries inside the example.

Recommendation

Add examples/bordeaux-template-robot as a minimal command-based Java 17 robot. Keep the robot behavior intentionally simple, but make every Bordeaux integration point real: annotated factories, a generated registry, trajectory loading from deploy, elapsed-time event polling, path-end cancellation, and simulation-safe command behavior.
