The editor controls are smaller and document units now survive reopening. The code cleanup removes redundant machinery while preserving planner and Java runtime behavior.

Editor changes

  • Routine and path pickers share the same compact width and truncation rules.
  • Document settings replaces the toolbar unit toggle. It contains one Metric/Imperial choice, available from Plan, Aquitaine, and Robot.
  • Display units are saved in optional editor.unitSystem metadata. Old files remain valid; invalid values are rejected at the file boundary. Geometry and exported measurements remain SI.
  • Waypoint up/down buttons are removed. Pointer dragging remains, with arrow-key reordering on the drag grip.
