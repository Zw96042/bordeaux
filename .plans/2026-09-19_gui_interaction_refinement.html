Limits and follow-up boundary

This is a focused desktop interaction pass, not a full accessibility certification. Native Windows/Linux, screen readers, touch hardware, native installers, and a live robot were not exercised. No new UI library or dependency was added.

The renderer application budget increased from 519 to 522 KiB for shared keyboard/focus handling. The verified application bundle is 533,174 bytes and CSS is 139,770 bytes; the generic bundler 500 kB advisory remains, while the repository’s renderer budget passes.

Robot execution of output branches still requires a typed completion result, output/schema validation, deterministic route evaluation, missing-output/error behavior, and an explicitly versioned robot export/runtime contract. The GUI does not claim live command outputs during local preview.
