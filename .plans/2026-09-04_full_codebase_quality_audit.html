Repairs and cleanup

  • Consolidate three heading-transition implementations into the existing typed module used by both production math engines and unit tests. Preserve distinct spline-seed and coupled-planner scheduling policies.
  • Stop replacing malformed routine step arrays with empty arrays during file normalization; validation now reports damaged input.
  • Make Java build reservation/cancellation cover asynchronous preflight as well as the spawned process. Serialize MCP bridge start/stop and clean failed startup resources.
  • Keep numeric typing and modal keyboard events from triggering background editor tools and deletions; refresh brush shortcut state when selecting tools.
  • Clear pending inspection state when replacing robot pairing so future refreshes remain usable. Use a native diagnostic dialog to contain keyboard focus, and clamp typed numeric edits while rejecting invalid or nonfinite input.
  • Reject initial generated motion exceeding its descriptor's limits; regression cases cover both linear and angular speed.
  • Correct agent repair scoring for upper-bound height constraints and zero measurements. Route Windows Java integration wrappers through the appropriate command interpreter.
  • Enable unused local/parameter diagnostics in TypeScript and remove the existing unused bindings and an unused test calculation.
