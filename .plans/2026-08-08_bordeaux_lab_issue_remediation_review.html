Five actionable Bordeaux reports are fixed and verified; two LabVIEW binary-contract reports remain open because they require external golden evidence that cannot be reconstructed safely.

Review scope

This pass inspected all seven open reports on the Bordeaux Lab board, their attachments and follow-up comments, the relevant renderer, planner, validation, and Electron session paths, and the compatibility invariants in AGENTS.md. The implementation stays additive: existing planners and the proven v4.4 file contract are not reinterpreted.

Implementation review

  • Planner behavior: the shared TypeScript planner, LabVIEW-compatible adapter, and static renderer use the same heading-anchor ownership rule. Existing endpoint and turn-in-place behavior is preserved.
  • State safety: the Electron boundary now treats renderer publications as transient input. Strict publication still throws for callers that need validation, while IPC uses the non-throwing path and retains the last valid snapshot.
  • UI primitives: the existing Java command picker became a shared primitive. Suggested values remain easy to select, unknown imported values remain intact, and exact new runtime values remain authorable.
  • Footprint model: optional preset metadata preserves editable parameters without changing the actual polygon used by collision checks. Validation covers preset ranges, convexity, the robot origin, and the robot envelope.
