Delivery limitation

The obsolete JSON runtime deployment was removed. The new LabVIEW BDX file reader does not provide a robot delivery receiver with readback and acknowledgment. Actual Push therefore stops locally, explains the missing receiver and offers BDX export for one selected path. Routines autosave as editable files, but routine deployment and execution are not implemented by this pass. No new robot protocol was invented or sent to XPS.

Parameter schemas now carry NI value types. Catalog fingerprints changed, so the robot catalog definitions must be regenerated during the later robot integration pass. The BDX byte layout itself is unchanged. The local Mac build is unsigned and has not been published as a release.

Decisions

Shift-click applies to authored canvas/outline features; library multi-selection retains its explicit desktop selection behavior. Proportional anchors move with path length; distance anchors retain meters from the path start. Existing waypoint-local ranges remain readable and can be converted. Explicit Save writes project settings; opening a folder establishes the autosave destination for editable paths and routines.
