## Body

Hi,

A robot path is more than a curve on a field. It has to agree with the robot’s geometry, motion limits, event timing, routine structure, and runtime commands.

That is why I built **Bordeaux**, a focused desktop editor for FRC autonomous authoring.

In the current beta, you can:

- shape paths with waypoints, headings, events, and local constraints;
- play trajectories back on the field and inspect timing;
- compose full autonomous routines in Aquitaine;
- model the drivetrain and robot footprint;
- connect typed Java command events through a versioned export contract; and
- review every agent proposal before applying it.

Bordeaux never edits `RobotContainer` and never deploys robot code. It is beta software, so validate every exported trajectory in simulation and on a safely controlled robot before relying on it in competition.

**Download the beta:** https://github.com/Zw96042/bordeaux/releases

If you try it, I would love a reproducible issue, a rough edge, or a workflow Bordeaux still makes harder than it should be.

Draw the path. Know the run.

— Zachary
