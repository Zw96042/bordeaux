## LinkedIn / longer feed

The visible path is only one part of an autonomous routine. The harder problem is keeping geometry, motion limits, event timing, robot shape, routine structure, and runtime command identity in agreement.

Bordeaux is a new beta desktop editor built around that complete handoff. Teams can author paths, preview motion, compose full routines in Aquitaine, define the physical robot, and connect typed Java command events through a deterministic export contract.

Automation stays reviewable: agent planning is optional, bounded, and staged behind explicit Apply/Reject controls. Bordeaux does not edit `RobotContainer` or deploy to the robot.

Download the beta, inspect the source, and share feedback:
https://github.com/Zw96042/bordeaux
